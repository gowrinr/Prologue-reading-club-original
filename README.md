# PROLOGUE – The Reading Club of LBSITW

A responsive membership portal website designed for **PROLOGUE – The Reading Club of LBSITW**.

## About the Project

PROLOGUE is a reading community that brings together students who share an interest in books, literature, creativity, and meaningful conversations.

This website was created as a digital membership portal for the club.

## Features

- Cinematic introductory section
- Responsive design for desktop and mobile
- About PROLOGUE section
- Why Join PROLOGUE section
- Activities and Events sections
- Interactive flip cards
- Image gallery with hover effects
- Membership registration form
- Form validation
- Contact and social media section
- Smooth scrolling navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
